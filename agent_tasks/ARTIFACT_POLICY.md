# Codex Queue Artifact Policy

## Track

Track source code that defines the local Codex queue package:

- `ai_orchestrator/codex_queue/*.py`
- focused tests in `tests/test_codex_queue_*.py`
- `tests/conftest.py` when needed by those tests

Track queue templates:

- `agent_tasks/templates/*.json`

Track operator documentation and package evidence:

- `agent_tasks/*.md`
- `docs/ORCH_SYMPHONY_*.md`
- `docs/ORCH_SYMPHONY_*.json`
- explicitly selected pilot evidence docs

## Usually Do Not Track

Queue runtime state should usually remain untracked:

- `agent_tasks/inbox/`
- `agent_tasks/approved/`
- `agent_tasks/planned/`
- `agent_tasks/review/`
- `agent_tasks/done/`
- `agent_tasks/blocked/`
- `agent_tasks/running/`

These directories contain task packets, handoff prompts, plans, review packets, locks, and state transitions generated by local operator activity. They are operational state, not package source, unless a file is intentionally promoted as a documented sample fixture.

Reports should also usually remain untracked:

- `agent_tasks/reports/`

Reports are generated outputs. Preserve a report only when it is needed as a milestone result, and stage that file by exact path after reviewing it for local paths and sensitive content.

## Staging Rule

Do not use any broad root staging command in this workspace:

- forbidden: `git add .`
- forbidden: `git add -A`
- forbidden: `git add --all`

Use explicit paths only. Prefer exact file lists over directory adds because the workspace contains many unrelated untracked files and Python bytecode directories.

## Ignore Guidance

There is currently no root `.gitignore`. This policy does not create one.

If the operator later approves a minimal ignore update, review entries such as:

```gitignore
__pycache__/
*.py[cod]
agent_tasks/inbox/
agent_tasks/approved/
agent_tasks/planned/
agent_tasks/review/
agent_tasks/done/
agent_tasks/blocked/
agent_tasks/running/
agent_tasks/reports/
```

Do not add broad ignores for unrelated project areas without a separate review.
