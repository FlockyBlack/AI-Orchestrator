Дашборд

Панель управления PMBOT

Здесь собраны подключение, баланс, аналитика, запуск, готовность и безопасная остановка. Панель остаётся статической: данные берутся из локальных диагностических артефактов и появляются только после read-only проверок в Telegram / CLI.

Финальная проверка требуется Перед запуском нужна явная операторская проверка.

Help

Run commands

  • Runtime credential diagnostic python -m pm_bot.operator_runner.runtime_credential_visibility_diagnostic --market BTC --strategy tiny-momentum --dry-run
  • Funder wallet diagnostic python -m pm_bot.operator_runner.funder_wallet_context_diagnostic --market BTC --strategy tiny-momentum --dry-run
  • Live account readonly probe python -m pm_bot.operator_runner.live_account_readonly_state_probe --market BTC --strategy tiny-momentum --dry-run
  • First supervised tiny order readiness packet python -m pm_bot.operator_runner.first_supervised_tiny_order_readiness_packet --market BTC --strategy tiny-momentum --dry-run
Команды создают локальные артефакты для просмотра

Mini App не запускает эти команды и не вызывает API. Оператор выполняет их отдельно в CLI.
