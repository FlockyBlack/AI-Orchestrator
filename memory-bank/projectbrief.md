# Project Brief

AI-Orchestrator - локальная система управления планами Codex/PMBOT: очередь задач, operator panel, execution packets, auto-ingestion и проверяемые result artifacts.

PMBOT - paper-only проект до отдельного будущего разрешения. Текущие работы строят безопасный контур симуляции, evidence capture, operator review и автоматизацию без реальных действий на рынках.

Текущий automation stack:

- 022: operator panel и plan-runner
- 023: queue/state resume и recovery
- 024: Codex execution packet и result ingestion
- 025: real Codex CLI invocation и auto-ingestion path
- 026: Symphony-style workspace/session model и app-server schema boundary
- 027: real short-lived Codex app-server dry-run succeeded
- 028: AGENTS.md, subagent roles, memory-bank, phase memory, receipts, maintenance templates

Статус PMBOT: paper-only. Реальные wallet/signing/orders/trading endpoints отключены.
