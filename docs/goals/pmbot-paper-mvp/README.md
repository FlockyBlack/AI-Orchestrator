# PMBOT Paper MVP Goal Board

Этот каталог хранит Goal Maker-style board для supervised PMBOT paper MVP.

Files:

- `goal.md` - цель, milestone range и safety constraints.
- `state.yaml` - компактное состояние board.
- `receipts/README.md` - правила receipts.
- `receipts/receipt_template.json` - шаблон результата milestone/task.

Receipts обязательны для implementation tasks: они связывают код, тесты, artifacts, safety flags и next task.
