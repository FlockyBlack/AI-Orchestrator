# PMBOT Crypto Source Quality Capture Surface

Task: `PMBOT-CRYPTO-PILOT-004-CRYPTO-SOURCE-QUALITY-CAPTURE-SURFACE-LOCAL-ONLY`

Surface: `crypto-source-quality-capture-surface`
Contract: `pmbot_crypto_source_quality_capture_surface.v1`
Run mode: `local_descriptive_crypto_source_quality_capture_surface`
Operator review: `pending_operator_review`

## Purpose

This surface defines a local, deterministic source quality capture layer for crypto pilot records. It inventories existing local crypto pilot fixtures, records required-field visibility, and keeps every row pending operator review.

The surface is descriptive recordkeeping only. It does not compute outcomes, rank sources, rank markets, or choose an operator path.

## Operator Review Boundary

Operators review whether the listed local artifacts, contract versions, and required fields are visible and copied into the surface accurately. Review status remains `pending_operator_review` until a human updates a later artifact.

The surface records field presence and local lineage only. It does not settle a market, resolve an observation, compare threshold values, or approve runtime use.
