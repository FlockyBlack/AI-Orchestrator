AI-Orchestrator V1 is a local-first task orchestration scaffold for reducing manual handoff between ChatGPT, OpenFlow/OpenClaw, and Codex.

V1 uses local task files plus Codex CLI `exec` as the execution path, with compact JSON reports and one task mapped to one fresh Codex session.

Out of scope for V1: Notion, Telegram, MCP, ChatGPT UI automation, and Codex App automation as the primary executor.
